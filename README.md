# Tourism Package Prediction (MLOps)

End-to-end MLOps project for "Visit with Us": predict whether a customer will purchase the Wellness Tourism Package (`ProdTaken`) from customer and sales-interaction data. A GitHub Actions pipeline registers the dataset, prepares train/test splits, tunes and tracks an XGBoost model with MLflow, and commits the trained model back to this repository. A Streamlit app in `tourism_project/deployment/` serves predictions from that committed model.

## Repository structure

```
.
├── .github/workflows/pipeline.yml          # CI/CD pipeline (3 jobs)
├── Learner_Template_Notebook_AML_and_MLOps_Project.ipynb   # Source notebook (all files below are generated by its %%writefile cells)
└── tourism_project/
    ├── data/tourism.csv                    # Dataset (4,128 rows, 20 columns + unnamed index column)
    ├── model_building/
    │   ├── data_register.py                # Validates expected columns, prints a dataset summary
    │   ├── prep.py                         # Cleans data, stratified 80/20 split -> Xtrain/Xtest/ytrain/ytest.csv
    │   └── train.py                        # GridSearchCV over an XGBoost pipeline, MLflow tracking, saves model
    ├── deployment/
    │   ├── app.py                          # Streamlit app
    │   ├── requirements.txt                # App dependencies
    │   └── best_tourism_model.joblib       # Trained model, committed by the pipeline (github-actions[bot])
    └── requirements.txt                    # Pipeline dependencies
```

## Pipeline (`.github/workflows/pipeline.yml`)

Triggered on every push to `main` and manually via "Run workflow".

1. `register-dataset`: installs `tourism_project/requirements.txt` and runs `data_register.py`, which checks the dataset columns and logs shape, target distribution and missing values.
2. `data-prep`: runs `prep.py` (drops the unnamed index column and `CustomerID`, maps the `Gender` typo "Fe Male" to "Female", stratified 80/20 split with `random_state=42`) and uploads the four split CSVs as the `data-splits` artifact.
3. `model-traning`: downloads `data-splits`, runs `train.py` (StandardScaler + OneHotEncoder + XGBClassifier, 16-candidate grid with 5-fold CV on F1, `scale_pos_weight` set from the training class ratio), logs every candidate and the best model to MLflow, uploads `mlruns/` as the `mlruns` artifact, and commits `tourism_project/deployment/best_tourism_model.joblib` back to `main` with `[skip ci]`.

Test-set metrics for each run are printed in the "Model Building" step log of the `model-traning` job.

## Deploy on Streamlit Community Cloud

Live app: https://tourism-package-prediction-vhr42ddpnk5pemwuryym52.streamlit.app

1. Sign in at https://share.streamlit.io with the GitHub account that owns this repository.
2. Click "Create app" and set:
   - Repository: `ravi-stiwari/tourism-package-prediction`
   - Branch: `main`
   - Main file path: `tourism_project/deployment/app.py`
3. Under "Advanced settings", set Python version to 3.11.
4. Click "Deploy". Streamlit installs `tourism_project/deployment/requirements.txt` and starts the app.

## Run the app locally

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r tourism_project/deployment/requirements.txt
streamlit run tourism_project/deployment/app.py
```
